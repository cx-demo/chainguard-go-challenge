Confidence definition

Confidence is not a vulnerability severity rating. It measures how many of four independent correlation signals agree between govulncheck and Trivy for a finding:

  • Reachability: govulncheck reports a reachable source symbol path.
  • Package: the exact Go package/module name matches.
  • Version: the installed Trivy package version matches govulncheck's version for that same module.
  • CVE ID: the Trivy CVE identifier is present as the exact CVE ID in the govulncheck advisory or its aliases.

High means 4/4 signals match. Moderate means 3/4. Limited means 1-2/4. Unmatched means 0/4. Trivy severity is an independent scanner assessment, not an input to confidence. A low-confidence result is not proof of safety, and high confidence is not proof of exploitability.

Trivy OS-package rows are excluded from Go correlation. Matching uses advisory IDs and published aliases; it does not infer matches from similar-looking CVE numbers or titles. Different scanner databases, image build toolchains, and advisory data can affect results.
